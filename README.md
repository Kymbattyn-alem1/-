# Ономастический кроссворд — СРС № 15

Интерактивный учебный кроссворд по основным разделам ономастики.

## Возможности
- 12 вопросов по ономастике;
- ввод ответов в клетки кроссворда;
- мгновенная проверка ответов;
- подсказки и подсчёт результата;
- показ правильных ответов;
- копирование результата для обратной связи.

## Запуск локально
Откройте файл `index.html` в браузере.

## Публикация через GitHub Pages
1. Создайте новый репозиторий GitHub.
2. Загрузите `index.html` в корень репозитория (рядом с README.md).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. После публикации откройте адрес сайта, указанный в разделе Pages.

Сайт работает как статическая HTML-страница: сервер и база данных не требуются. Ответы пользователей не отправляются на сервер.
